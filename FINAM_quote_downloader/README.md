# Загрузка биржевых котировок с сайта ФИНАМа.  
Python 3.13

[rts_finam_downloader_tick_to_zip_csv.py](rts_finam_downloader_tick_to_zip_csv.py) - 
качает тиковые котировки на фьючерс RTS c Финама.
Преобразует дату и время, добавляя условные миллисекунды для сохранения порядка.
До 1000 сделок в секунду используется шаг 1 мс; при большем количестве шаг
уменьшается до долей миллисекунды. Все сделки сохраняются в исходном порядке,
метки не выходят за пределы исходной секунды. Это не биржевая точность времени.
Сохраняет данные за каждый день в заархивированный (zip) файл csv. 
Объем загруженных данных за 10 лет, составляет около 1,8 Gb.  

### Запуск исправленного ZIP-загрузчика

Из корня `quote_download` в PowerShell:

```powershell
.\.venv\Scripts\python.exe .\FINAM_quote_downloader\rts_finam_downloader_tick_to_zip_csv.py --start 2022-02-11 --end 2022-02-11 --output .\data\finam_probe --timeout 15 --attempts 1
```

Без аргументов используются настройки внизу скрипта: RTS, папка
`C:\data_quote\data_finam_RTS_tick_zip`, период с 01.01.2025 по вчерашний день.
Существующие ZIP не перезаписываются. Для изменения диапазона доступны
`--start`, `--end`; для папки — `--output`. Полная справка: `--help`.

Загрузчик обращается к `https://export.finam.ru/export9.out` — адресу,
указанному в [официальной форме экспорта RTS](https://www.finam.ru/quote/forts/rts/export/).
Форма также передаёт `finam_token`. Вход в аккаунт для гостевого токена не нужен.
Если переменная `FINAM_TOKEN` не задана, модуль `finam_guest_token.py` получает
гостевой токен автоматически, передаёт его в экспорт и повторно получает токен
перед истечением срока действия. Токен и случайный идентификатор устройства
хранятся только в памяти процесса. Дополнительные библиотеки не требуются.
Существующие ZIP пропускаются до обращения к авторизации.

Используется провайдер `FINAMRU_DEVICE_ID` из публичной
[конфигурации сайта](https://ga-cdn.finam.ru/config/v1/finamRu.json).
Адрес сервера читается из конфигурации; запрос повторяет `Auth` из
[виджета авторизации](https://libs-cdn.finam.ru/auth-widget/@8.js).
Это внутренний протокол сайта, который может измениться.

Ручной `FINAM_TOKEN` имеет приоритет; его обновлением занимается пользователь.
Посмотреть токен можно в исходной вкладке страницы экспорта: `F12` → `Console`
и выполнить выражение, которое использует сама форма:

```javascript
(await FinamAuth.getWidget()).TxGlobalAuth.getJwt().token
```

Новую вкладку загрузки открывать для этого не требуется. Ещё один вариант —
`Ctrl+J`, копирование ссылки завершённой загрузки и поиск параметра `finam_token`.
Не публикуйте токен и не записывайте его в Git; токен Trade API не подходит.
Чтобы снова использовать автоматическую гостевую авторизацию, удалите ручное
значение из текущего PowerShell:

```powershell
Remove-Item Env:FINAM_TOKEN -ErrorAction SilentlyContinue
```

Сетевые ошибки повторяются ограниченное число раз, после чего обработка
останавливается с ненулевым кодом возврата. Ошибка не считается пустым торговым
днём. Ответ проверяется на структуру CSV, дату, порядок времени, цену и объём.
Готовый ZIP появляется только после успешного завершения записи.

Проверка 28.09.2026: конфигурация сайта доступна, но соединение с сервером
авторизации `ftrr04.finam.ru` при включённом VPN завершилось тайм-аутом.
Пользователь подтвердил выгрузку через сайт без входа в аккаунт после отключения
VPN. Автоматическое получение реального токена и выгрузка новым кодом пока
не подтверждены; проверены локально на моделируемых ответах сервера.
При следующей возможности отключите VPN и повторите однодневную пробу выше
в отдельную папку, чтобы не затрагивать ранее загруженные архивы.

Проверки без сети:

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s FINAM_quote_downloader -p "test_*.py" -v
```

### Тиковый ZIP-загрузчик MIX

`mix_finam_downloader_tick_to_zip_csv.py` создан на основе рабочего загрузчика RTS.
Он использует `SPFB.MIX` (ID Финама `81408`, код экспорта `MIX`), проверенный по
[форме экспорта MIX](https://www.finam.ru/quote/forts/mix/export/).
Гостевая авторизация, проверки CSV, условные временные метки, пропуск готовых
архивов и параметры командной строки работают так же, как у RTS.

По умолчанию: папка `C:\data_quote\data_finam_MIX_tick_zip`,
период с 01.01.2025 по вчерашний день. Для загрузки с 2022 года:

```powershell
.\.venv\Scripts\python.exe .\FINAM_quote_downloader\mix_finam_downloader_tick_to_zip_csv.py --start 2022-01-01
```

Проверка одного дня в отдельной папке:

```powershell
.\.venv\Scripts\python.exe .\FINAM_quote_downloader\mix_finam_downloader_tick_to_zip_csv.py --start 2022-02-11 --end 2022-02-11 --output .\data\finam_mix_probe --timeout 15 --attempts 1
```

### Настраиваемые параметры
1. `dir_data` - путь до целевой папки, куда будут складываться скаченные файлы.
2. `ticker` - тикер.
3. `period` - в исправленном ZIP-загрузчике только `1` (тики).
В остальных загрузчиках возможны периоды от тиков до часов; один файл соответствует одному дню.
period: int =  
Выбор из: 'tick': 1, 'min': 2, '5min': 3, '10min': 4, '15min': 5, '30min': 6, 'hour': 7
4. `market` - маркет (акции/фьючерсы)
5. `daft` - формат данных. Для исправленного ZIP-загрузчика только `9`; остальные
форматы ниже перечислены для справки по сервису и другим скриптам.
datf - Формат получения данных  
datf = 1 'TICKER, PER, DATE, TIME, OPEN, HIGH, LOW, CLOSE, VOL'  
datf = 2 'TICKER, PER, DATE, TIME, OPEN, HIGH, LOW, CLOSE'  
datf = 3 'TICKER, PER, DATE, TIME, CLOSE, VOL'  
datf = 4 'TICKER, PER, DATE, TIME, CLOSE',  
datf = 5 'DATE, TIME, OPEN, HIGH, LOW, CLOSE, VOL',  
datf = 6 'TICKER, PER, DATE, TIME, LAST, VOL',  
datf = 7 'TICKER, DATE, TIME, LAST, VOL'  
datf = 8 'TICKER, DATE, TIME, LAST',  
datf = 9 'DATE, TIME, LAST, VOL',  
datf = 10 'DATE, TIME, LAST',  
datf = 11 'DATE, TIME, LAST, VOL, ID'  
6. `start_date_range` - Дата начиная с которой качать котировки
7. `end_date_range` - Дата по которую качать котировки (включительно)


[settings.py](settings.py) - 
файл settings.py содержит данные в основном по акциям Московской биржи (MOEX).
Проверьте наличие тикера в файле settings.py!!!  
Если вашего тикера там нет, то добавьте его. ID можно узнать на сайте ФИНАМа.  
Можно добавлять как акции, так и фьючерсы.  
[rts_erase_zero_file_csv.py](rts_erase_zero_file_csv.py) 
После закачки, в целевой папке будут и файлы с нулевым размером (не для zip файлов). 
Это файлы за выходные или праздничные дни, когда торги на бирже не велись. 
Чтобы очистить целевую папку от пустых файлов, запустите erase_zero_files.py.  
Перед запуском очистки пропишите путь к целевой папке.  
Переменная `path_storage`
## Изменения
Теперь запрос к серверу Финама включает в себя заголовок, чтобы сервер думал, 
что к нему обращается браузер.
