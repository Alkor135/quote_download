# Загрузка исторических данных биржевых котировок.  

[FINAM_quote_downloader](FINAM_quote_downloader) - для загрузки тиковых данных с сервера ФИНАМа.  

[MOEX_ISS_API_quote_downloader](MOEX_ISS_API_quote_downloader_apimoex) - загрузка котировок с официального сервера MOEX.  
Бесплатные данные только начиная с минутных.  
Можно скачивать данные и по опционам с открытым интересом.

[MOEX_ISS_API_quote_downloader_day2](MOEX_ISS_API_quote_downloader_day2) — два
самостоятельных скрипта для дневной истории фьючерсов RTS и MIX с 2018 года
по вчерашний день. На каждый торговый день сохраняются два ближайших контракта
с включением дня экспирации. Повторный запуск заполняет все пропуски в периоде.
Для дня без сделок отсутствующие OHLC могут заполняться предыдущим закрытием
того же контракта с отдельной отметкой в `FilledQuotes`.
БД SQLite 3: `C:\data_quote\day2\RTS_day2.db` и `C:\data_quote\day2\MIX_day2.db`.
